# Qlippy

<p align="center"><img src="qlippy.svg" alt="Qlippy" width="240"></p>

Inspired by nothing in particular, Qlippy is here to maybe help you with everything you do in QGIS.

## Features

- Can actually provide advice
- Mostly doesn't actually provide advice
- Lots of animations
- Lots of commentary
- Settings to get more animations and commentary
- Settings to get less, but really, what's the point?

## Usage

- **Click** Qlippy for a tip or remark.
- **Double-click** it for a random animation.
- **Drag** it to move it.
- **Right-click** it for the menu: Say something, Go exploring, Animate (a random animation), Help/Harass level, Snooze, Settings and Hide.
- The toolbar button shows or hides Qlippy. Settings are also in **Plugins > Qlippy**.
